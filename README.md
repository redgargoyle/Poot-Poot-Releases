# Poot-Poot — Wonderwild Zoo

Public downloads of Kadabra Games’ six-rescue browser prototype.

**[Download the portable browser edition](https://github.com/redgargoyle/Poot-Poot-Releases/releases/tag/browser-2026-10-10)** · [Play online](https://kadabra.games/play/poot-poot/)

The download runs locally on Windows, macOS, or Linux and requires **Python 3 and a modern browser**. Extract the entire ZIP, then follow `START-HERE.txt`. Windows users can open `Play Poot-Poot.bat`; Linux/macOS users can run `sh "Play Poot-Poot.sh"` in the extracted folder. Keep its terminal open while playing.

This is a portable browser edition, not a native executable. It includes all game artwork and sound; it works offline once Python and the browser are installed. Saves belong to the browser and local address, separate from the online game.

Checksums are attached to the release. This repository distributes the playable package; the studio’s maintained website source remains in its private repository.
